# QA 보류 항목 (2026-11-26)

전체 QA에서 발견했지만, 정책이나 디자인 판단이 필요해서 고치지 않은 항목입니다.
바로 고친 버그는 같은 날 커밋에 들어 있습니다.

## 알림

- **알림 시간대가 서울로 고정됨**
  - 위치: `lib/services/notification_service.dart`의 `tz.setLocalLocation(tz.getLocation('Asia/Seoul'))`
  - 해외 사용자는 플랜 알림이 엉뚱한 시각에 옵니다. 예를 들어 LA에서 07:00으로 설정하면 현지 시각 전날 14:00에 옵니다.
  - 고치려면 `flutter_timezone` 같은 패키지를 추가해서 기기 시간대를 읽어야 합니다.

## 말씀 카드

- **긴 범위를 카드로 만들면 글이 잘림**
  - 위치: `lib/widgets/bible_card_layouts/*_layout.dart`
  - 카드는 1080x1350 고정 크기이고, 글자 크기를 최소 26~28px까지만 줄입니다. 그래서 약 500~600자를 넘으면 본문과 출처가 잘립니다(예: 창세기 1장 1~10절 범위 선택 후 공유).
  - 시스템 글자 크기를 키운 기기에서는 더 짧은 본문에서도 넘칩니다.
  - 정할 것: 글자를 더 줄일지, 카드로 만들 수 있는 글자 수를 제한할지, 카드를 여러 장으로 나눌지.

## 번역본

- **성경일독 플랜과 오늘의 말씀은 항상 개역개정**
  - 플랜 화면은 `loadBibleJson()`(개역개정)을 고정으로 씁니다. 오늘의 말씀은 `lib/models/today_verse_model.dart`에 하드코딩된 목록입니다.
  - 사용자가 표준새번역이나 KJV를 골라도 반영되지 않습니다. 의도된 동작인지 정해야 합니다.
  - 플랜에 다른 번역을 붙이려면 `lib/utils/extract_verses.dart`의 정규식도 고쳐야 합니다. 지금은 한글 책 이름(`[가-힣]`)만 처리합니다.
- **번역본을 바꾸면 읽던 위치와 선택이 초기화됨**
  - 위치: `lib/screens/bible/bible_home_screen.dart`의 `_onLanguageChanged`
  - 본문을 읽다가 상단 번역본 칩(개역개정 ▾)으로 번역을 바꾸면 화면을 새로 만듭니다. 그래서 스크롤이 처음 들어온 절로 돌아가고, 여러 절을 범위 선택해 둔 것도 풀립니다.
  - 같은 이유로, 단어 검색 화면에서 Eng 버튼을 누르면 검색 모드와 결과가 사라지고 책 목록으로 돌아갑니다.
- **번역본을 빠르게 연달아 바꾸면 데이터와 언어가 어긋날 수 있음**
  - 위치: `bible_home_screen.dart`의 `_onLanguageChanged`
  - JSON 로드에 순서 보장이 없습니다. 먼저 시작한 로드가 나중에 끝나면, 언어는 KJV인데 데이터는 한글인 상태가 되어 절 목록이 빕니다.
- **하이라이트와 북마크를 번역 구분 없이 저장함**
  - 위치: `verse_list_view.dart`, `favorite_verse.dart`
  - 번역마다 절 수가 다른 장(시72, 아6, 겔15, 계12, 고후13, 요삼1)에서는 하이라이트가 다른 내용의 절에 칠해질 수 있습니다.
  - 개역개정에서 북마크한 구절을 KJV에서 다시 북마크하면 아무 반응 없이 무시됩니다.

## 성경 데이터

- **표준새번역에서 마지막 절이 앞 절에 합쳐진 곳**
  - 시편 72편: 20절이 19절 끝에 붙어 있습니다.
  - 에스겔 15장: 8절이 없습니다.
  - `assets/bible_snb.json` 원본 데이터의 문제입니다.

## 성경일독 플랜

- **60일 플랜에서 장이 겹침**
  - 위치: `lib/models/bible_60.dart`
  - 46/47일차가 `마1~16장` / `마16~28장`, 49/50일차가 `눅1~12장` / `눅12~24장`입니다.
  - 마태복음 16장과 누가복음 12장을 두 번 읽게 됩니다. 분량을 맞추려는 의도였을 수도 있습니다.

## 오늘의 말씀

- **날짜가 바뀌어도 그대로 보임**
  - 위치: `lib/screens/todayVerseCard/today_verse_card.dart`(`_loadTodayVerse`가 initState에서만 호출됨), `home_screen.dart`의 날짜 줄
  - 밤에 말씀을 뽑고 앱을 백그라운드에 둡니다. 다음 날 아침 돌아오면 어제 말씀과 어제 날짜가 그대로 있습니다.
  - 고치려면 앱이 다시 열릴 때(생명주기 resume) 날짜를 확인해서 새로 그려야 합니다.

## 퀴즈

- **같은 질문이 한 파일 안에 중복됨**
  - 한 판 10문제 안에 같은 문제가 두 번 나올 수 있습니다.
  - 해당 id:
    - `mc_easy_023 / 081 / 135`
    - `mc_easy_001 / 107`
    - `mc_easy_009 / 028`
    - `mc_easy_054 / 141`
    - `mc_easy_098 / 108`
    - `ox_easy_012 / 073`
    - `ox_easy_058 / 088`
- **정답이 애매한 문제** (해석에 따라 다름)
  - `mc_hard_008`: 엘가나의 지파. 삼상 1:1은 에브라임 사람, 대상 6장은 레위입니다.
  - `mc_easy_010`: 첫 제자를 베드로로 봄. 요 1:40 기준으로는 안드레입니다.
  - `mc_easy_012`: 오병이어 장소가 "산 위". 마 14:15 기준으로는 빈 들입니다.
  - `mc_hard_091`: 스가랴의 검은 말을 "굶주림"으로 봄. 이는 계 6:5의 해석입니다.
  - `mc_hard_098`: 오순절 사건을 "다른 민족에게 복음을 전함"으로 봄. 행 2:4는 다른 언어로 말한 사건입니다.
  - `mc_hard_080`: 질문의 "길르앗에서"가 갈멜산과 맞지 않습니다.
  - `mc_medium_143`: "곡간"에 본문 근거가 없습니다(창 44:14은 요셉의 집).
- **퀴즈 기록이 문제 원본을 그대로 저장함**
  - 위치: `lib/models/quiz_history.dart`
  - 정답 데이터를 고쳐도, 예전 기록의 상세 화면에는 틀린 정답이 그대로 "정답"으로 보입니다.
- **퀴즈 도중 시스템 뒤로가기**
  - 위치: `quiz_play_screen.dart`
  - 확인 창 없이 바로 퀴즈가 종료됩니다. 종료 확인을 넣을지 정해야 합니다.
